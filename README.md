# RESPAN: Автоматическое обнаружение и анализ дендритных шипиков

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)

> **RESPAN** (REsponsive SPine ANalyzer) — система автоматического обнаружения дендритных шипиков на микроскопических изображениях с использованием предобученных моделей глубокого обучения и вейвлет-методов для валидации результатов.

---

## 📌 О проекте

Проект **project7_spines** посвящен разработке и валидации методов автоматического анализа дендритных шипиков — микроскопических выростов на дендритах нейронов, играющих ключевую роль в синаптической передаче и пластичности мозга.

### Актуальность
Ручная разметка дендритных шипиков экспертами-биологами — трудоемкий и субъективный процесс. RESPAN автоматизирует эту задачу, обеспечивая высокую скорость анализа, воспроизводимость результатов и объективность детектирования.

### Научный контекст
Проект выполняется в рамках прикладного проекта Южного федерального университета (ЮФУ) по направлению «Гибридные нейросетевые и вейвлет-методы ИИ для реконструкции корковой активности и декодирования мысленных команд в мобильных системах ЭЭГ с ограниченным числом отведений».

## ✨ Возможности

- 🤖 **Автоматическое обнаружение** дендритов и шипиков на 3D z-stack изображениях.
- 📊 **Сравнительный анализ** с экспертной разметкой (биологи + MAE).
- 📈 **Визуализация результатов** с выделением совпадений и расхождений.
- 🧮 **Статистический анализ** качества детектирования по 4 категориям.
- ⚙️ **Гибкая настройка** параметров анализа через YAML-конфигурацию.
- 📦 **Готовые примеры** использования в Jupyter Notebook.
